## 🇰🇷 한국어

### 📌 소개
**Souls Save Manager**는 여러 PC 환경에서 게임을 즐기거나 USB 드라이브를 활용하는 유저분들을 위한 다크 소울 3, 엘든 링, 세키로의 세이브 파일 백업 및 빠른 교체(Quick Swap) 유틸리티 프로그램입니다. 

파일 탐색기를 직접 열어 경로를 찾아다닐 필요 없이 클릭 한 번으로 세이브 파일을 관리할 수 있습니다.

### 🚀 핵심 기능
* **간편 백업**: 현재 인게임 세이브 상태를 안전하게 저장합니다.
* **빠른 교체 (Quick Swap)**: 백업해 둔 다른 세이브 파일로 즉각 전환합니다.
* **멀티 게임 지원**: 다크 소울 3, 엘든 링, 세키로 모두 완벽히 호환됩니다.
* **휴대성 극대화**: USB 드라이브에 프로그램을 담아 여러 PC를 오가며 편리하게 세이브를 동기화할 수 있습니다.

### 🎮 사용 방법
1. **사전 준비**: 프로그램을 실행하기 전, 관리 대상 게임을 최소 1회 이상 정상 실행 완료해야 합니다.
2. **주의 사항**: 게임을 완전히 종료했거나, 게임 메인 타이틀 로고 화면(PRESS ANY BUTTON이 표시된 상태)에서만 세이브 백업 및 교체를 진행해 주세요.
3. USB나 원하는 로컬 디렉토리에 본 프로그램을 설치한 뒤 실행하여 세이브를 교체/관리합니다.

### ⚠️ 이용 시 주의점
* **단일 계정 전용**: 본 프로그램은 현재 PC당 1개의 활성화된 Steam 계정(싱글 계정) 환경을 기준으로 최적화되어 있습니다. 다중 계정을 이용할 경우 각 계정마다 세이브 폴더가 별도로 생성되므로, 경로 관리에 대한 주의가 필요합니다.

### 📅 업데이트 기록 & 로드맵

* **2023.08.24**:

* **💡 향후 계획 (Roadmap)**:

## 🇺🇸 English

### 📌 Introduction
**Souls Save Manager** is a lightweight, high-performance utility designed to back up and rapidly swap save files for *Dark Souls III*, *Elden Ring*, and *Sekiro: Shadows Die Twice*. 

It is ideal for players who use multiple PCs, run their games from portable USB drives, or need to manage different character builds effortlessly without manually navigating deep folder structures.

### 🚀 Key Features
* **One-Click Backup**: Safely back up your current active save game.
* **Quick Swap (QS)**: Instantly swap between your custom backup save points.
* **Multi-Game Support**: Seamlessly manage save files for *Dark Souls III*, *Elden Ring*, and *Sekiro*.
* **Portable Utility**: Place the manager on a USB drive alongside your saves for an instant "plug-and-play" experience on any PC.

### 🎮 How to Use
1. **Initial Setup**: Run each supported game at least once on your PC before opening the Save Manager.
2. **Safety Notice**: Make sure to either exit the game fully or stay on the game's title screen ("PRESS ANY BUTTON") before performing backups or swapping files.
3. Place `Souls Save Manager` in your USB or preferred directory, and launch to start managing your saves.

### ⚠️ Important Warnings
* **Single Account Limitation**: The utility is currently tested and optimized for a single Steam account per PC. If you use multiple Steam accounts, separate folders will be created by the game, which might require manual adjustments.

### 📅 Changelog & Roadmap
* **2023.08.29**:
  * Exception Handling improvements:
    * Prevented crashes when duplicating, select-swapping, or performing Quick Swaps when save files do not exist.
* **2023.08.24**:
  * Full integration of all three games (*Dark Souls III*, *Elden Ring*, and *Sekiro*).
* **💡 Roadmap (Future Plans)**:
  * Character Slot Profile Swapping: Support swapping specific character slots selectively (e.g., swapping a Lv.125 Knight + Lv.60 Mage profile into a Lv.125 Mage + Lv.60 Pyromancer profile).

## 🇨🇳 简体中文

### 📌 介绍
**Souls Save Manager (魂系游戏存档管理器)** 是一款专为《黑暗之魂3》、《艾尔登法环》和《只狼：影逝二度》设计的轻量级、高效率存档备份与快速替换工具。

本程序免去了您频繁手动寻找游戏存档路径的繁琐操作，非常适合在多台电脑间游玩、使用U盘运行以及需要灵活切换不同角色存档（Build）的玩家。

### 🚀 核心功能
* **一键安全备份**: 安全备份您当前正在进行的游戏存档。
* **快速替换 (Quick Swap)**: 在备份的存档点之间实现瞬间闪存式替换。
* **多游戏管理**: 完美支持《黑暗之魂3》、《艾尔登法环》和《只狼》。
* **便携即插即用**: 支持直接在U盘运行，轻松实现多台电脑间的存档携带与同步。

### 🎮 使用方法
1. **前期准备**: 在首次启动本管理器之前，请确保目标游戏已在当前PC上至少运行过一次。
2. **安全建议**: 请务必在游戏完全关闭、或处于游戏主标题界面（"PRESS ANY BUTTON"）时再使用本程序进行存档的操作。
3. 将本程序解压放入U盘或常用本地路径中，双击运行即可。

### ⚠️ 注意事项
* **单账号测试**: 目前仅针对单Steam账号环境进行了优化测试。若您在同一台电脑上使用多个Steam账号，游戏会生成对应的多个存档文件夹，这可能需要您手动调整存档路径。

### 📅 更新日志 & 未来规划
* **2023.08.29**:
  * 异常逻辑优化：
    * 修复了在游戏存档不存在的情况下进行复制、选择替换以及快速替换（QS）时引发的程序异常报错。
* **2023.08.24**:
  * 完美集成《黑暗之魂3》、《艾尔登法环》及《只狼》三大游戏的存档整合管理。
* **💡 未来规划 (Roadmap)**:
  * 精准存档槽位替换：计划加入更精准的存档槽位选择性替换功能（例如：将 125级骑士 + 60级法师 的存档组合，一键替换为 125级法师 + 60级咒术师 存档）。
